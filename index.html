Objective

WebGIS yang menghubungkan peta dengan data operasional

Plantation Spatial Explorer adalah portfolio WebGIS yang menunjukkan bagaimana satu spatial unit — Plantation Block — bisa terhubung langsung ke data operasional kebun kelapa sawit: production, yield, fertilizer, hingga leaf sampling. Dibangun di atas MapLibre GL JS dan MAPID API sebagai final project WebGIS Development Bootcamp, sekaligus eksplorasi personal saya di luar ekosistem ArcGIS Enterprise.

Spatial Data

Estate & Plantation Block dari MAPID API, dengan local GeoJSON sebagai fallback.

Operational Data

Production, yield, dan fertilizer monitoring — terhubung ke tiap block lewat kode block.

Spatial Analysis

Bukan sekadar map viewer — memilih satu block akan membaca konteks di sekitarnya.

Data

Data yang dipakai

Semua data di project ini adalah dummy/simulasi milik perusahaan fiktif PT Mencari Cinta Sejati — dibuat untuk demonstrasi, bukan kebun sungguhan.

Spasial

Estate & Plantation Block

Geometry & atribut dari MAPID API: BLOCK, DIVISION, AREA, PLANT_YEAR, status kematangan.

  • 1 Estate · 2 Division · 30 Block
  • ±458 ha luas total
Operasional

Production & Yield

Tonase FFB, jumlah tandan, dan yield per block per periode — basis peta tematik Production.

  • TONNAGE_TON, YIELD_TON_HA
  • BUNCH_COUNT
Agronomy

Fertilizer Monitoring

Dosis & status aplikasi pupuk per periode — basis peta tematik Fertilizer Status.

  • DOSAGE_KG_HA
  • STATUS — Applied / Planned
Agronomy

Leaf Sampling (LSU)

Hasil analisis nutrisi daun per block, ditampilkan sebagai nutrient balance chart.

  • N_PERCENT, P_PERCENT
  • K_PERCENT
Fitur

Yang bisa dilakukan di Dashboard

Enam kemampuan inti, semua saling terhubung lewat satu block yang dipilih di peta.

Interactive Map

Navigasi Estate & Block, popup detail, search block dengan autocomplete, filter per Division.

KPI & Overview

Ringkasan Division, Block, Area, dan Yield yang mengikuti filter, lengkap chart Block Maturity.

Production & Fertilizer Map

Peta tematik yield dan status pupuk per block, digeser lewat slider periode bulanan.

Operational Spatial Analysis

Block Benchmark, Nearby Analysis, dan Performance Cluster — membandingkan satu block dengan block di sekitarnya, secara spasial.

Measure Tool

Ukur jarak (meter) dan luas (hektar) langsung di peta, dengan live preview saat menggambar.

Print Map

Ekspor peta ke layout siap cetak A4/A3, lengkap judul, legend, dan scale bar.
